# Lyricod 0.5.7

This update fixes Lyricod Glass's liquid effect filling with solid colour, and makes NetEase Cloud Music sync and the floating island more dependable.

- **Lyricod Glass**: the liquid effect shows what's behind the island again. On some Windows 11 versions it could pick up the island itself and fill with solid, saturated colour until Lyricod restarted. When the liquid effect starts, the island now leaves screenshots and recordings for under a second. If the liquid effect can't start or stops working, the island falls back to clear glass.
- **NetEase Cloud Music sync**: Lyricod only runs the sync helper version it was released with, checks it before running it, and keeps it from being replaced in the meantime. Setting up sync shows the same progress and result on every settings page, and Lyricod finds NetEase Cloud Music even when an older installation left entries behind.
- **Floating island**: it stays on the display where you drop it. A spot saved by an earlier version at a display's right or bottom edge now stays on that display.
- **Mini player gesture**: moving across the hidden island and then down opens the mini player only when the move down passes over the island.
- **Settings**: the Lyricod Glass effect descriptions are more accurate.

### Download

- **Lyricod-0.5.7-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.7-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.7-windows-x64.zip** / **Lyricod-0.5.7-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Session-specific capture exclusion requires Windows 11 build 26100 or newer and runtime interface availability. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
