# Lyricod 0.5.6

This update improves recording compatibility for Lyricod Glass while keeping its live Liquid effect.

- **Screenshots and recordings**: on supported Windows 11 versions, the live Liquid Glass island can appear in screenshots and desktop recordings, including NVIDIA Instant Replay. Lyricod excludes the island only from its own background capture, preserving live blur, refraction, tint and highlights.
- **Older Windows versions**: when session-specific exclusion is unavailable, Lyricod keeps the existing capture protection to prevent visual feedback. Use **Show in screenshots** to temporarily include the island in a capture.

### Download

- **Lyricod-0.5.6-windows-x64-setup.exe**: installer for most Windows PCs (Intel and AMD).
- **Lyricod-0.5.6-windows-arm64-setup.exe**: installer for Arm-based PCs.
- **Lyricod-0.5.6-windows-x64.zip** / **Lyricod-0.5.6-windows-arm64.zip**: portable versions. Extract and run `Lyricod.exe`, keeping the `app` folder beside it.

Settings and cached lyrics are kept when updating. Lyricod supports in-app updates from version 0.3.1 onward; older versions need a manual update. If you switch from the zip to the installer and had startup enabled, turn it off and back on in Settings > General.

Requires Windows 10 version 1809 or newer. Music-reactive island bars and Lyricod Glass's liquid effect require Windows 11; on Windows 10, Lyricod Glass stays clear. Session-specific capture exclusion requires Windows 11 build 26100 or newer and runtime interface availability. Lyricod is currently unsigned, so Windows may show a warning when you first run it.
